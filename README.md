# City-Fix-Community-Infrastructure-Reporting-Platform

## Overview

City Fix is a mobile application designed to improve communication between citizens and local authorities by providing a simple platform for reporting and tracking community infrastructure issues. The application allows users to submit reports for problems such as potholes, damaged streetlights, flooding, and waste management concerns while enabling staff and administrators to manage and resolve issues efficiently.

## Features

* User registration and secure authentication
* Report infrastructure issues with descriptions and categories
* Real-time issue tracking and status updates
* Role-based access control for Citizens, Staff, and Administrators
* Cloud-based data storage and management
* Issue assignment and workflow management
* Mobile-friendly user interface

## System Architecture

1. Citizens submit infrastructure reports through the mobile application.
2. Reports are stored securely in Firebase Firestore.
3. Staff members review and manage assigned issues.
4. Administrators oversee system operations and user management.
5. Users receive real-time updates as issues progress from submission to resolution.
